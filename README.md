# Findr - Smart Lost and Found Portal

A lightweight, modern, responsive Smart Lost & Found Web Portal with client-side smart fuzzy matching, secure verification prompts, and instant deployment support for **AWS Amplify** and **AWS S3**.

## Features
- **Smart Pattern Matcher**: Cross-checks lost reports against found listings to identify matching items.
- **Ownership Verification**: Built-in verification question prompt to prevent wrongful claims.
- **Filter & Search**: Real-time multi-attribute search across categories, statuses, and locations.
- **Single-File Architecture**: Self-contained `index.html` with Tailwind CSS and FontAwesome CDN.

## Deploying to AWS Amplify (Recommended - Under 2 minutes)
1. Open the [AWS Management Console](https://console.aws.amazon.com/).
2. Search for **AWS Amplify** and click **Host your web app** (or **Deploy without Git**).
3. Set your App Name (e.g., `findr-lost-and-found`).
4. Drag and drop this `findr-lost-and-found.zip` file directly into Amplify.
5. Click **Save and Deploy**. Your live HTTPS shareable URL will be generated immediately!
